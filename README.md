# Sistema de Gestão e Locação de Frota

Projeto desenvolvido em Python com o objetivo de simular um sistema simples de gestão e locação de veículos. A aplicação funciona pelo terminal e permite controlar veículos disponíveis, realizar aluguéis, calcular o valor total por diária e registrar devoluções.

## Objetivo do projeto

O objetivo deste projeto é praticar conceitos fundamentais de lógica de programação, organização de dados e criação de sistemas interativos em Python.

## Funcionalidades

- Listar veículos disponíveis para aluguel
- Alugar um veículo pelo modelo
- Calcular automaticamente o valor total com base na quantidade de dias
- Marcar o veículo como indisponível após o aluguel
- Devolver veículo utilizando o código do veículo
- Menu interativo no terminal

## Tecnologias utilizadas

- Python
- Listas
- Dicionários
- Funções
- Estruturas condicionais
- Laços de repetição
- Entrada e saída de dados pelo terminal

## Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/caiquesouzasantos92-devs/sistema-gestao-locacao-frota.git
```

2. Acesse a pasta do projeto:

```bash
cd sistema-gestao-locacao-frota
```

3. Execute o arquivo Python:

```bash
python Frota.py
```

## Exemplo de uso

Ao iniciar o programa, o sistema apresenta um menu com as opções:

```text
Escolha a opção:
1. Listar Veículos
2. Alugar Veículo
3. Devolver Veículo
4. Sair
```

O usuário pode listar os veículos disponíveis, realizar o aluguel de um veículo, calcular o valor total pelas diárias e registrar a devolução.
